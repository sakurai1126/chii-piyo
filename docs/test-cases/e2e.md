# E2Eテストケース

| ケースID | シナリオ | 観点 | 期待結果 |
| ------ | -------------------- | --- | -------------------------------- |
| E2E-01 | ログイン〜ホーム表示 | 正常 | 正しい認証情報でログインしホームのサマリーが表示される |
| E2E-02 | 未ログインでの保護ページアクセス | 権限 | 認証なしで保護ページへ遷移するとログイン画面へリダイレクトされる |
| E2E-03 | ログイン失敗 | 異常 | 不正な認証情報ではログインできずエラーが表示される |
| E2E-04 | 写真アップロード〜一覧表示 | 正常 | アップロードした写真がアップロード完了後に一覧へ表示される |
| E2E-05 | アルバム作成〜写真追加〜アルバム閲覧 | 正常 | 作成したアルバムに写真が追加され詳細で閲覧できる |
| E2E-06 | メディアの削除〜ゴミ箱〜復元 | 正常 | 削除がゴミ箱に移動し復元で元の一覧に戻る |
| E2E-07 | ゴミ箱からの完全削除 | 正常 | 完全削除するとゴミ箱から消え復元不可になる |
| E2E-08 | 育児記録のワンタップ登録〜カレンダー反映 | 正常 | ワンタップ記録がカレンダーに反映される |
| E2E-09 | 共有範囲の設定による表示制御 | 権限 | 設定した共有範囲に応じてメディアの表示が制御される |
| E2E-10 | 管理者と閲覧者による操作可否の差 | 権限 | ロールに応じて操作可能な機能が出し分けられる |
| E2E-11 | かんたんモードによる表示切り替え | 正常 | かんたんモードのユーザーには簡素化されたUIが表示される |
